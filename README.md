# 🗺️ Digital Desert Interactive Dashboard

**Bridging the Digital Divide by Uncovering Digital Deserts Hackathon**

An interactive web-based dashboard for visualizing and analyzing connectivity gaps, flood vulnerability, and indigenous community locations across North-eastern Cambodia.

---

## ✨ Features

### 📊 6 Interactive Sections:

1. **🏠 Overview** - Executive summary with key metrics
   - Total villages, registered lands, families
   - Quick risk assessment
   - Challenge context

2. **📍 Interactive Map** - Visual geospatial exploration
   - Toggle village markers
   - Filter by ethnic group
   - Display registered communal lands
   - Zoom, pan, interact with features

3. **📈 Provincial Analysis** - Statistical comparisons
   - Provincial summary table
   - Indigenous communities by province
   - Registered lands distribution
   - Population and area comparisons

4. **⚠️ Flood Vulnerability** - Risk assessment
   - Population exposure analysis
   - Area flooded comparisons
   - Risk ranking and severity
   - Critical findings highlights

5. **👥 Indigenous Communities** - Demographic insights
   - Ethnic group distribution (pie chart)
   - Geographic spread by province
   - Land statistics and distributions
   - Family and area metrics

6. **💡 Insights** - Recommendations & strategy
   - Digital desert typologies
   - Strategic recommendations
   - Intervention framework
   - Actionable policy guidance

## 🚀 Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Dashboard
From the `numpum/` directory:
```bash
streamlit run dashboard.py
```

The dashboard will open in your browser at `http://localhost:8501`

### 3. Explore
- Use the sidebar menu to navigate between sections
- Interact with maps, charts, and filters
- Hover over data points for details
- Export charts using the menu (top-right of each plot)

## 📁 Data Requirements

The dashboard expects these files in `./processed_data/`:

```
processed_data/
├── 01_provincial_summary.csv
├── 02_flood_risk_analysis.csv
├── 03_connectivity_statistics.csv
├── 04_indigenous_villages_mrd.geojson
├── 05_indigenous_registered_lands.geojson
├── 06_villages_with_risk_context.geojson
├── 07_osm_telecom_towers.geojson
├── 07b_osm_water_points.geojson
├── 08_digital_desert_communities.geojson
├── 09_digital_desert_summary.csv
├── 10_model_thresholds.csv
└── 11_province_model_metrics.csv
```

Files `01`-`06` come from the ETL pipeline (`etl.ipynb`).
Files `07`-`11` are generated by the modeling pipeline (`python build_digital_desert_model.py`).

### New External Sources Added (Modeling Update)

1. **OpenStreetMap (telecom proxy points) via Overpass API**
   - Primary endpoint: `https://overpass-api.de/api/interpreter`
   - Fallback endpoint: `https://overpass.kumi.systems/api/interpreter`
   - Generates: `07_osm_telecom_towers.geojson`

2. **OpenStreetMap (waterway/water proxy points) via Overpass API**
   - Primary endpoint: `https://overpass-api.de/api/interpreter`
   - Fallback endpoint: `https://overpass.kumi.systems/api/interpreter`
   - Generates: `07b_osm_water_points.geojson`

3. **OpenTopoData (SRTM90m elevation)**
   - Endpoint: `https://api.opentopodata.org/v1/srtm90m`
   - Enriched into: `08_digital_desert_communities.geojson`

No new paid or proprietary source was added in this update; only free/open sources were used.

## 📊 Key Insights

### Digital Desert Typologies

| Type | Description | Provinces | Action |
|------|-------------|-----------|--------|
| **A: High-Risk/Low-Coverage** | Flood-prone, many exposed | Kampong Thom, Kratie | Deploy emergency systems |
| **B: Remote Indigenous** | Culturally isolated, low connectivity | Ratanakiri, Mondulkiri, Stung Treng | Language-aware training |
| **C: Under-resourced** | Limited infrastructure data | Preah Vihear | Assess & prioritize |

### Critical Numbers
- **58** indigenous villages identified
- **4,234** families in registered communities
- **2.9M+** people exposed to flooding (3-month period)

## 📖 Narrative

**The Story Behind the Data:**

Samorn Pich (23, Bunong from Mondulkiri) and Pin Plil (22, Bunong) live in a digital black hole. Their villages have no internet connectivity while facing extreme vulnerability to seasonal floods. Without early warning systems, they cannot evacuate in time. Without broadband, they cannot sell produce online or access digital services.

This dashboard transforms raw geospatial and demographic data into **actionable evidence** that their challenge is real, measurable, and solvable with targeted infrastructure investment.

## 🔄 Data Refresh

To update the dashboard with new data:

1. Re-run the ETL pipeline: `jupyter notebook etl.ipynb`
2. Rebuild digital desert modeling outputs: `python build_digital_desert_model.py`
   - This regenerates separate `flood_exposure_score` and `topographic_susceptibility_score` fields, while `risk_score` remains the composite ranking score.
3. Ensure new files are in `./processed_data/`
4. Restart Streamlit: `streamlit run dashboard.py`

See: `MODELING_UPDATE.md` for methodology and assumptions.
See: `ARCHITECTURE_DIAGRAMS.md` for ETL/architecture/modeling diagrams.
